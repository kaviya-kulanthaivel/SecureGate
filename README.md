# SecureGate

## Secure Authentication System using Flask

SecureGate is a web-based authentication system developed using Python Flask. It provides a secure user registration and login system with password protection.

## Features
- User Registration
- Secure Login
- Password Hashing
- Forgot Password Page
- Dashboard
- SQLite Database
- Responsive UI

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Project Structure
```
SecureGate/
│── app.py
│── users.db
│── static/
│   └── style.css
│── templates/
    ├── login.html
    ├── register.html
    ├── forgot.html
    └── dashboard.html
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/kaviya-kulanthaivel/SecureGate.git
   ```

2. Install Flask:
   ```bash
   pip install flask
   ```

3. Run the application:
   ```bash
   python app.py
   ```

4. Open your browser and visit:
   ```
   http://127.0.0.1:5000
   ```
